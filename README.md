# app2

Shared Flutter foundation for the app2 mobile application.

## Requirements

- macOS
- Git
- Flutter (stable channel)
- Android Studio with the Flutter and Dart plugins
- Xcode for iOS development

Verify the local toolchain with:

```sh
flutter doctor -v
```

## Getting started

```sh
git clone https://github.com/ChloeP07/app2.git
cd app2
flutter pub get
flutter run
```

Select an Android emulator, iOS simulator, or connected phone when prompted.
The initial screen displays `app2` to confirm that the project is running.

## Project details

- Flutter package: `app2`
- Android application ID: `com.sereneandchloe.app2`
- iOS bundle identifier: `com.sereneandchloe.app2`
- Supported platforms: Android and iOS

The HTML files in the repository are design references and are not part of the
Flutter application.
